# 醒脑原理卡片 · Adaptive Cognition Cards

自适应认知引擎（醒脑）48 机制编号卡片。每张卡是一个**最小自解释单元**：编号、一句话机制、机制出处、失效条件（不适用边界）。

把任意一张卡（图片或文本）丢给任意大模型，它都能讲清楚。不需要安装 skill。

- English README → [README.md](README.md)

## 项目背景

自适应认知引擎（醒脑）是一个基于行为经济学、进化心理学、博弈论的决策 skill：每天早上一个大白话认知段子，六大模块、48 条机制轮换。这套卡片就是机制库的沉淀形态——设计目标是**任意 AI 只看一张卡，就能知道整个项目背景**：引擎是什么、48 条机制如何编号、编号永不重用/重排的契约。每张卡片底部都印着本仓库地址，就是为此准备的。

## 以编号引用

引用只报编号，如 **M06-06**（杀死自己的共识）。编号是契约：**新机制只拿新编号，老编号永不重用、永不重排。**

## 为什么"不适用"框最重要

原理是公共品——哪个模型都知道。卡片里真正抄不走的，是**失效条件**：那一行"什么时候不适用"。引用时连边界一起引用，这才是编号的价值。

## 姊妹项目：卦象情境卡

这套卡回答"为什么会这样"（机制）。姊妹项目回答"你现在在哪"：[卦象情境卡](https://github.com/goldof/hexagram-situation-cards)——源自《易经》64 卦的 64 张编号情境卡（YI01–YI64）。每张卡都是情境透镜（非占卜：不预测、不给建议），64 张卡连成一张验证过的 384 边转移图——卡告诉你在哪，边告诉你局面能走向哪。

两套卡按编号互相引用：拿一张 YI 卡（处境）配 M 卡（起作用的机制），情境 × 机制 = 完整诊断。如 YI47（困）× M02-01（损失厌恶）。

## 自适应：把这套卡变成你自己的

这 48 张卡是种子，不是终点。"自适应"有三层：

1. **选卡分析**：对任意事件或场景，挑 1–3 张相关的卡，用"机制＋出处＋不适用"去拆它。比如看到"网红产品翻车"，先报 M08-02（基率忽视）再报 M06-06（杀死自己的共识）——卡是分析的抓手，不是答案。
2. **Fork 并长出你自己的编号**：fork 本仓库，按同一格式加你自己的卡。铁律只有一条：新卡只拿新编号（从 M12 往后排），老编号永不重用、永不重排。你的卡和我的卡可以互相引用。
3. **做成你自己的 skill**：把 cards.md 喂给你的 AI 助手，告诉它"以后分析问题，先选卡、再引用编号、最后检查不适用框"——这就是一个最小可用的认知 skill。文本免费，跑起来是你的事。

原理是公共品，编号是你的。卡片的价值不在 48 这个数字，而在"一编号一机制一边界"这个格式——格式是骨架，内容可以无限长。
