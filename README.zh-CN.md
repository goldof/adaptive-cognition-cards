# 醒脑原理卡片 · Adaptive Cognition Cards

自适应认知引擎（醒脑）48 机制编号卡片。每张卡是一个**最小自解释单元**：编号、一句话机制、机制出处、失效条件（不适用边界）。

把任意一张卡（图片或文本）丢给任意大模型，它都能讲清楚。不需要安装 skill。

- English README → [README.md](README.md)

## 以编号引用

引用只报编号，如 **M06-06**（杀死自己的共识）。编号是契约：**新机制只拿新编号，老编号永不重用、永不重排。**

| 编号 | 模块 |
|------|------|
| M01-01 – M01-06 | 博弈拉锯与锚定策略 |
| M02-01 – M02-05 | 说服框架转换 |
| M03-01 – M03-06 | 沉没成本与战略止损 |
| M04-01 – M04-03 | 认知摩擦力跨越 |
| M05-01 – M05-04 | 思维反刍物理打断 |
| M06-01 – M06-06 | 反共识引擎 |
| M07-01 – M07-04 | 认知科学 |
| M08-01 – M08-04 | 统计思维 |
| M10-01 – M10-03 | 科学史（证伪案例库） |
| M11-01 – M11-07 | 古典决策智慧 |

## 为什么"不适用"框最重要

原理是公共品——哪个模型都知道。卡片里真正抄不走的，是**失效条件**：那一行"什么时候不适用"。引用时连边界一起引用，这才是编号的价值。

## 引用图片

每张卡的官方图片地址固定，可直接引用，无需重新生成：

```
https://raw.githubusercontent.com/goldof/adaptive-cognition-cards/main/{zh|en}/png/xingnao-{编号}.png
```

例：`.../main/zh/png/xingnao-M01-01.png`。`cards.json` 里每条也自带 `image_url` 字段。
